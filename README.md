# Intern Application Portal

An internship application page with a validated form and status information,
built with HTML only (no CSS, no JavaScript).
Task 4 of my Bloomrix internship.

## Files
- index.html - the application portal page
- images/portal-map.svg - image used for the image map
- images/quick-apply.svg - image used for the image input

## How to run
Open index.html with Live Server in Visual Studio Code, or in any web browser.
